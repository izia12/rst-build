## Текущая задача: Раскраска по прилегаемости к стержневым элементам

### Описание задачи
Необходимо реализовать новую систему раскраски элементов:
- **Светло-голубой цвет**: для фигур, прилегающих к стержневым элементам (имеющих общие узлы)
- **Желтый цвет**: для фигур, не прилегающих к стержневым элементам

### Техническая реализация

#### Этап 1: Анализ структуры данных
- Определить как идентифицируются стержневые элементы в SLI файлах
- Проанализировать структуру узлов и их связи

#### Этап 2: Алгоритм определения прилегаемости
```rust
// Псевдокод для определения общих узлов
fn has_common_nodes(element1: &Element, element2: &Element) -> bool {
    element1.nodes.iter().any(|node1| 
        element2.nodes.iter().any(|node2| node1 == node2)
    )
}
```

#### Этап 3: Система раскраски
